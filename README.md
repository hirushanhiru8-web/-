# MKV School T-Shirt Ordering Website — V2

A premium mobile-first alternative design for KG/DEHI/MUDUGAMUWA.K.V.

## Email delivery
The form uses FormSubmit and posts orders to **hirushanhiru8@gmail.com**. On the first live submission, FormSubmit may ask you to confirm/activate the destination email. After activation, submitted orders are emailed automatically.

## GitHub Pages
1. Upload the contents of this folder to a GitHub repository.
2. Settings → Pages → Deploy from branch → main → /root.
3. Open the GitHub Pages URL.
